# School Result Portal

A web-based Academic Result Management System built with PHP and MySQL.

The system allows administrators to manage students, subjects, and results while allowing students to check their academic performance online.

---

## Features

- Admin authentication system
- Add and manage students
- Add and manage subjects
- Record student results
- Session and semester support
- GPA calculation
- Edit and delete results
- Student result checker
- Printable result slip
- Admin dashboard statistics

---

## Technologies Used

- PHP
- MySQL
- Bootstrap
- JavaScript / AJAX
- HTML & CSS

---

## System Modules

### Admin Panel

Admins can:

- Login securely
- Add students
- Add subjects
- Add results
- View results
- Edit results
- Delete results
- View system statistics

### Student Portal

Students can:

- Enter matric number
- Select session
- Select semester
- View their results
- Print result slip

---

## Installation

1. Clone the repository

2. Move the project folder into your web server directory

Example for XAMPP: htdocs/school-result-portal

3. Import the database file into phpMyAdmin

4. Configure the database connection in:config/db.php


5. Run the project in your browser:

http://localhost/school-result-portal
